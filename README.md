# Red ou blue?

Exercício de condicionais em `escolher_cor.por`: escolhe azul ou vermelho por uma única letra, sem diferenciar maiúsculas de minúsculas.

## Como executar

No Portugol Studio 2.7.5, abra o arquivo `.por`, execute-o pelo botão ▶ e responda no console quando solicitado.

## Exemplos

| Entrada | Saída |
|---|---|
| `b` ou `B` | `Cor azul` |
| `r` ou `R` | `Cor vermelha` |
| `blue`, `x` ou linha vazia | `Opção inválida. Digite B ou R.` |
